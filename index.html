VISION ÓTICAS
Consultoria visual para vendedores

Encontre a armação ideal.

Fotografe o cliente, informe o formato do rosto e compare os modelos cadastrados na sua ótica. Funciona sem conta e sem servidor.

1. Foto do cliente

Foto ou câmera

Selecione uma imagem do cliente para iniciar a consultoria.

Privacidade: a imagem permanece neste navegador e não é enviada para um servidor.

2. Avaliação do rosto

Nesta versão offline, a classificação do formato facial é feita pelo vendedor. Não há reconhecimento facial automático nem diagnóstico de medidas.

3. Recomendações

Selecione o formato do rosto e clique em “Ver recomendações”.

Pontuações são heurísticas estéticas, não medições clínicas. Conforto, largura, ponte, ajuste e preferência pessoal devem ser verificados presencialmente.

Cadastro de armações

O catálogo é salvo neste navegador. Exporte o JSON para fazer backup ou transferir a outra máquina.
